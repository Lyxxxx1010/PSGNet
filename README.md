# PSGNet

Project resources for the manuscript **Recovering Structural Priors from Degraded Rubbings for Oracle Bone Script Documentation with PSGNet**.

PSGNet investigates structural prior-guided detection of Oracle Bone Script in degraded rubbing images.

## Availability

This repository currently contains only this README. A representative subset of the dataset and selected parts of the code will be released in future updates. Dataset files and code are not yet available in this repository.
